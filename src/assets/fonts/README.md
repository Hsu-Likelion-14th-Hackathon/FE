# 웹폰트 자산

Figma에서 확인된 실제 사용 범위에 맞춰 배포에 필요한 파일만 보관한다.

## Pretendard 1.3.9

- 사용 파일: Regular 400, SemiBold 600 WOFF2 subset
- 라이선스: SIL Open Font License 1.1
- 전문: `public/licenses/PRETENDARD-LICENSE.txt`
- 원본: https://github.com/orioncactus/pretendard

## 느림보고딕

- 사용 파일: 제작자가 배포한 Regular 400 OTF 원본
- 저작권자: 이정은
- 웹사이트 및 프로그램 서버 임베딩 사용 가능
- 수정, 포맷 변환, 서브셋 및 폰트 파일 자체의 별도 재배포 금지
- 안내: https://www.sandollcloud.com/free-font/18209/NeurimboGothic
- 고지: `public/licenses/NEURIMBO-NOTICE.txt`

느림보고딕은 라이선스 조건을 지키기 위해 제공된 파일을 변환하지 않는다.
