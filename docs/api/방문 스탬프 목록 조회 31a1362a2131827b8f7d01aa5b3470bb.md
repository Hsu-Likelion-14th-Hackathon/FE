# 방문 스탬프 목록 조회

카테고리: Passport
설명: 여권에 적립된 방문 스탬프를 최신순으로 조회합니다. 각 스탬프는 방문 기록과 1:1로 대응하며, visitLogId로 방문 상세를 조회할 수 있습니다.
유형: GET
URL: /passport/stamps
상태: 시작 전
인증: 필요

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "totalVisitCount": 6,
    "stamps": [
      {
        "passportStampId": 6,
        "visitLogId": 3,
        "stampedOn": "2026-08-15",
        "stampAssetUrl": "https://.../stamp.png"
      }
    ]
  }
}
```

**404**

```json
{
  "isSuccess": false,
  "code": "PASSPORT_NOT_FOUND",
  "message": "발급된 여권이 없습니다."
}
```
