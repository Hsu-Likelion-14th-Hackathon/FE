# Boarding Pass 스캔

카테고리: Boarding Pass
설명: 매장 입구에서 Boarding Pass를 스캔 처리합니다. 심사 환경에서는 스캔 시뮬레이션 버튼으로 호출합니다. 방문 기록이 생성되고 AI 피팅 크레딧이 지급되며, 티켓 상태가 SCANNED로 전환됩니다. 이미 스캔된 티켓은 중복 처리되지 않습니다.
유형: POST
URL: /boarding-passes/{boardingPassId}/scan
담당자: 박세웅
상태: 시작 전
인증: 필요

### Path Parameters

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| boardingPassId | number | Y | 보딩패스 ID |

### Request Body

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| storeId | number | N | 매장 ID. 기본값 `1` (MCM HAUS) |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "boardingPassId": 7,
    "status": "SCANNED",
    "visitLogId": 3,
    "entryNo": "00001",
    "scannedAt": "2026-08-25T14:23:00",
    "earnedCredit": 50,
    "creditBalance": 150
  }
}
```

**400**

```json
{
  "isSuccess": false,
  "code": "ALREADY_SCANNED",
  "message": "이미 스캔된 Boarding Pass입니다."
}
```
