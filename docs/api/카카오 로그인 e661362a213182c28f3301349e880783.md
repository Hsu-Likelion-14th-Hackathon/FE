# 카카오 로그인

카테고리: 인증
설명: 카카오 인가 코드로 로그인합니다. 최초 로그인이면 회원을 생성하고 isNewUser: true를 반환하며, 이 경우 추가 정보 입력 API를 이어서 호출해야 합니다.
유형: POST
URL: /auth/kakao
상태: 시작 전
인증: 불필요

### Request Body

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| code | string | Y | 카카오 인가 코드 |
| redirectUri | string | Y | 인가 코드 발급에 사용한 리다이렉트 URI |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "accessToken": "eyJhbGci...",
    "isNewUser": true,
    "user": {
      "userId": 1,
      "name": null,
      "email": "ingosa@kakao.com"
    }
  }
}
```

**400**

```json
{
  "isSuccess": false,
  "code": "INVALID_AUTH_CODE",
  "message": "유효하지 않은 인가 코드입니다."
}
```
