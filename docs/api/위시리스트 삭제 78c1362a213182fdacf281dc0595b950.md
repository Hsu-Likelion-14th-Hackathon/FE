# 위시리스트 삭제

카테고리: 위시리스트 / 쇼핑백
설명: 위시리스트에서 상품을 제거합니다. 상세페이지의 하트 토글 해제 시 호출합니다.
유형: DELETE
URL: /wishlist/{productColorId}
상태: 시작 전
인증: 필요

### Path Parameters

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| productColorId | number | Y | 색상 단위 찜 (이거까지는 추후논의라 하긴했는데 아무리 생각해도 해야될 거 같아서 일단 구현..) |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "productId": 1,
    "isWished": false
  }
}
```

**404**

```json
{
  "isSuccess": false,
  "code": "WISHLIST_ITEM_NOT_FOUND",
  "message": "위시리스트에 없는 상품입니다."
}
```
