# 비행 종료 (매장 나가기)

카테고리: Boarding Pass
설명: 매장 관람을 종료합니다. 체류 시간이 계산되어 방문 기록에 저장되고, 여권에 방문 스탬프가 발급됩니다. 티켓 상태는 COMPLETED로 전환됩니다.
유형: POST
URL: /boarding-passes/{boardingPassId}/complete
담당자: 박세웅
상태: 시작 전
인증: 필요

### Path Parameters

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| boardingPassId | number | Y | 보딩패스 ID |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "boardingPassId": 7,
    "status": "COMPLETED",
    "stayMinutes": 46,
    "passportStampId": 6,
    "totalVisitCount": 6
  }
}
```

**400**

```json
{
  "isSuccess": false,
  "code": "NOT_SCANNED_YET",
  "message": "스캔되지 않은 Boarding Pass입니다."
}
```
