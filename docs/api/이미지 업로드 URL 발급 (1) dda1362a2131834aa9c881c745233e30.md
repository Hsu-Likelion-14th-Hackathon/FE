# 이미지 업로드 URL 발급 (1)

카테고리: AI 가상 피팅
설명: 이미지를 Azure Blob에 직접 올리기 위한 임시 업로드 URL(SAS)을 발급합니다. 이 API는 파일을 받지 않습니다. 발급받은 uploadUrl에 클라이언트가 직접 PUT으로 파일을 올린 뒤, fileKey를 이후 API에 사용합니다.
유형: POST
URL: /fitting-sessions/upload-url
담당자: 박세웅
상태: 완료
인증: 필요

### **Request Body**

| **이름** | **유형** | **필수** | **설명** |
| --- | --- | --- | --- |
| fileName | string | Y | 원본 파일명. 예: `me.jpg` (실제 파일 전송 아님) |
| contentType | string | Y | MIME 타입. **`image/jpeg`**, **`image/png`만 허용** |

```json
{
  "fileName": "me.jpg",
  "contentType": "image/jpeg"
}
```

### **Response**

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "uploadUrl": "https://mcmboardingpass.blob.core.windows.net/uploads/fitting%2Ftmp%2F....jpg?sv=...&sig=...",
    "fileKey": "fitting/tmp/026aa901-ec31-43ab-b84a-32349306d234_me.jpg",
    "expiresIn": 300
  }
}
```

| **필드** | **설명** |
| --- | --- |
| uploadUrl | Azure로 파일 올릴 주소. **5분(`expiresIn`) 안에** 사용 |
| fileKey | 이후 저장/피팅 요청에 넘길 키 |
| expiresIn | `uploadUrl` 만료 시간(초) |

400 - 지원하지 않는 타입

```json
{
  "isSuccess": false,
  "code": "FILE4002",
  "message": "지원하지 않는 이미지 형식입니다."
}
```

401

```json
{
  "isSuccess": false,
  "code": "COMMON401",
  "message": "인증이 필요합니다."
}
```

- 1번 호출 시 `Content-Type: application/json` + Bearer 토큰
