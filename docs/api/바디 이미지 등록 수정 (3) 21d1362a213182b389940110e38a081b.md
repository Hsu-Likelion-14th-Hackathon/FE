# 바디 이미지 등록/수정 (3)

카테고리: AI 가상 피팅, 인증
설명: Azure 업로드가 끝난 fileKey를 유저의 기본 전신(바디) 이미지로 저장합니다. 피팅 시 기본 이미지로 재사용할 수 있습니다. 파일을 다시 보내지 말고, 1번에서 받은 fileKey만 보냅니다.
유형: PUT
URL: /users/me/body-image
담당자: 박세웅
상태: 완료
인증: 필요

### **Request Body**

| **이름** | **유형** | **필수** | **설명** |
| --- | --- | --- | --- |
| fileKey | string | Y | 1번 응답의 `fileKey`. 반드시 `fitting/`으로 시작 |

```json
{
	"fileKey": "fitting/tmp/026aa901-ec31-43ab-b84a-32349306d234_me.jpg"
}
```

### **Response**

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "bodyImageUrl": "https://mcmboardingpass.blob.core.windows.net/uploads/fitting%2Ftmp%2F....jpg?sv=...&sig=..."
  }
}
```

| **필드** | **설명** |
| --- | --- |
| bodyImageUrl | 저장된 이미지 조회용 URL(읽기 SAS 포함). 미리보기/표시에 사용 |

**400** — fileKey 형식 오류

```json
{
  "isSuccess": false,
  "code": "FILE4003",
  "message": "유효하지 않은 파일 키입니다."
}
```

**401**

```json
{
  "isSuccess": false,
  "code": "COMMON401",
  "message": "인증이 필요합니다."
}
```

> 주의: 2번 Azure PUT을 안 하고 3번만 호출하면 DB에는 URL이 생길 수 있어도, 실제 Blob이 없어 이미지가 안 보일 수 있습니다. **반드시 2번 성공 후 3번** 호출하세요.
>

- 3번에는 `fileKey`만 JSON으로 전달
- 미리보기는 3번 응답의 `bodyImageUrl` 사용 (1번의 `uploadUrl`로 GET 하지 말 것)
