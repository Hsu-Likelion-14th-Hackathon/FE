# 내 정보 조회

카테고리: 인증
설명: 로그인한 회원의 기본 정보와 크레딧 잔액을 조회합니다.
유형: GET
URL: /users/me
상태: 시작 전
인증: 필요

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "userId": 1,
    "name": "박세웅",
    "email": "ingosa@kakao.com",
    "nationality": "Republic of Korea",
    "hasDefaultBodyImage": true,
    "creditBalance": 140
  }
}
```

**401**

```json
{
  "isSuccess": false,
  "code": "COMMON401",
  "message": "인증이 필요합니다."
}
```
