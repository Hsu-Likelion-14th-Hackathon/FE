# 여권 조회

카테고리: Passport
설명: 여권 신분면 정보를 조회합니다. 이름·국적은 회원 가입 시 입력한 값이며, 크레딧 잔액과 누적 방문 횟수가 함께 반환됩니다.
유형: GET
URL: /passport
상태: 시작 전
인증: 필요

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "passportNo": "0001",
    "name": "박세웅",
    "nationality": "Republic of Korea",
    "issuedOn": "2026-08-25",
    "creditBalance": 100,
    "totalVisitCount": 6
  }
}
```

**404**

```json
{
  "isSuccess": false,
  "code": "PASSPORT_NOT_FOUND",
  "message": "발급된 여권이 없습니다."
}
```
