# 추가 정보 입력

카테고리: 인증
설명: 최초 로그인 회원의 이름·생년월일·국적을 저장합니다. 이 정보는 이후 여권(Passport) 페이지에 그대로 표시됩니다. 저장 시 여권이 함께 발급되고 가입 크레딧이 지급됩니다.
유형: POST
URL: /auth/profile
상태: 시작 전
인증: 필요

### Request Body

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| name | string | Y | 이름 (여권 표기명) |
| birthDate | string | Y | 생년월일 `YYYY-MM-DD` |
| nationality | string | Y | 국적 (예: `Republic of Korea`) |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "userId": 1,
    "name": "박세웅",
    "birthDate": "2001-03-14",
    "nationality": "Republic of Korea",
    "passportNo": "0001",
    "creditBalance": 100
  }
}
```

**400**

```json
{
  "isSuccess": false,
  "code": "INVALID_BIRTH_DATE",
  "message": "생년월일 형식이 올바르지 않습니다."
}
```
