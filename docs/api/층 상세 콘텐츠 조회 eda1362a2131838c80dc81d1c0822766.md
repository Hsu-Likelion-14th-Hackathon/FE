# 층 상세 콘텐츠 조회

카테고리: Travel Guide (층 콘텐츠)
설명: 특정 층의 브랜드 스토리 콘텐츠를 노출 순서대로 조회합니다. blockType은 TEXT · IMAGE · PRODUCT · QUOTE · LIST이며, 연속된 LIST 블록은 하나의 목록으로 묶어 렌더링합니다. audioUrl은 사전 생성된 음성 도슨트 파일 URL입니다.
유형: GET
URL: /floors/{floorId}
담당자: 박세웅
상태: 완료
인증: 필요

### Path Parameters

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| floorId | number | Y | 층 ID |

### Response

"code": "ORIGIN", "title": "기원", "subtitle": "1976, MÜNCHEN", "tagline": "...”
