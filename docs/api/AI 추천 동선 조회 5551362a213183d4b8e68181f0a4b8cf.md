# AI 추천 동선 조회

카테고리: Boarding Pass
설명: 발급 시 계산된 층별 추천 동선을 순서대로 조회합니다. 각 단계에는 해당 층을 추천한 AI 생성 사유가 포함되며, 비행 모드 화면과 Travel Guide 진입에 사용합니다. 5개 층 전부 반환되며, isRecommended가 true인 층만 강조 표시합니다.
유형: GET
URL: /boarding-passes/{boardingPassId}/route
담당자: 박세웅
상태: 시작 전
인증: 필요

### Path Parameters

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| boardingPassId | number | Y | 보딩패스 ID |
