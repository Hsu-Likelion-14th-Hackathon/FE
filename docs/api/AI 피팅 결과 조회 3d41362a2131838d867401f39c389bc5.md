# AI 피팅 결과 조회

카테고리: AI 가상 피팅
설명: 피팅 세션의 처리 상태와 결과 이미지를 조회합니다. 로딩 화면에서 2초 간격으로 폴링하며, status가 DONE이 되면 resultImageUrl이 채워집니다. FAILED인 경우 차감된 크레딧은 자동 환급됩니다.
유형: GET
URL: /fitting-sessions/{fittingSessionId}
상태: 시작 전
인증: 필요

### Path Parameters

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| fittingSessionId | number | Y | 피팅 세션 ID |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "fittingSessionId": 12,
    "status": "DONE",
    "resultImageUrl": "https://s3.../result/abc.jpg",
    "product": {
      "productColorId": 1,
      "name": "Ottomar 비세토스 위켄더",
      "price": 1750000
    }
  }
}
```

**404**

```json
{
  "isSuccess": false,
  "code": "FITTING_SESSION_NOT_FOUND",
  "message": "존재하지 않는 피팅 세션입니다."
}
```
