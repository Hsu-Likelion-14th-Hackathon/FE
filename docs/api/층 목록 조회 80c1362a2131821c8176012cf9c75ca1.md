# 층 목록 조회

카테고리: Travel Guide (층 콘텐츠)
설명: 매장의 층 목록을 조회합니다. Travel Guide 첫 화면의 층 인덱스를 구성할 때 사용합니다.
유형: GET
URL: /floors
담당자: 박세웅
상태: 완료
인증: 필요

"code": "ORIGIN", "title": "기원", "subtitle": "1976, MÜNCHEN", "tagline": "...”
