# 기본 전신 이미지 삭제

카테고리: 인증
설명: 저장된 피팅용 바디 이미지를 삭제합니다. 삭제 후 피팅을 다시 하려면 이미지를 새로 업로드해야 합니다.
유형: DELETE
URL: /users/me/body-image
상태: 시작 전
인증: 필요

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "deleted": true
  }
}
```

**404**

```json
{
  "isSuccess": false,
  "code": "BODY_IMAGE_NOT_FOUND",
  "message": "저장된 바디 이미지가 없습니다."
}
```

**401**

```json
{
  "isSuccess": false,
  "code": "COMMON401",
  "message": "인증이 필요합니다."
}
```
