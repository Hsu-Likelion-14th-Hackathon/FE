# AI 피팅 요청

카테고리: AI 가상 피팅
설명: 업로드한 이미지와 상품을 조합해 가상 피팅 이미지 생성을 요청합니다. Upload URL 발급 → Azure Blob 업로드 이후, Fitting 버튼 클릭 시점에 호출합니다. 요청 시 크레딧이 차감되며, fileKey 미전달 시 회원의 기본 전신 이미지를 사용합니다. 잔액이 부족하면 실패합니다. 응답은 즉시 PENDING으로 반환되고, 결과는 조회 API로 폴링합니다.
유형: POST
URL: /fitting-sessions
상태: 시작 전
인증: 필요

### Request Body

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| productColorId | number | Y | 착용할 상품 색상 ID |
| fileKey | string | N | 새로 업로드한 파일 키. 미전달 시 회원의 기본 전신 이미지 사용 |
| saveAsDefault | boolean | N | `true`면 이 이미지를 기본 전신 이미지로 저장. 기본값 `true` |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "fittingSessionId": 12,
    "status": "PENDING",
    "creditCost": 10,
    "creditBalance": 130
  }
}
```

**400**

```json
{
  "isSuccess": false,
  "code": "INSUFFICIENT_CREDIT",
  "message": "크레딧이 부족합니다. 매장 방문 시 충전됩니다."
}
```
