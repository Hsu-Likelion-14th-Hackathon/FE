# 크레딧 내역 조회

카테고리: Passport
설명: 크레딧 적립·차감 내역을 최신순으로 조회합니다. amount가 양수면 적립, 음수면 차감입니다. 여권 화면의 크레딧 잔액 하단 내역 목록에 사용합니다.
유형: GET
URL: /passport/credits
상태: 시작 전
인증: 필요

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "creditBalance": 130,
    "histories": [
      {
        "creditLedgerId": 4,
        "amount": -10,
        "reason": "FITTING",
        "description": "Ottomar 비세토스 위켄더 가상 피팅",
        "balanceAfter": 130,
        "createdAt": "2026-08-25T15:02:00"
      }
    ]
  }
}
```

**401**

```json
{
  "isSuccess": false,
  "code": "COMMON401",
  "message": "인증이 필요합니다."
}
```
