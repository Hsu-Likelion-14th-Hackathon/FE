# 방문 상세 조회

카테고리: Passport
설명: 특정 방문 회차의 상세 기록을 조회합니다. 입장번호·체류 시간과 함께 당시 발급받은 티켓 정보와 관람한 층 동선이 반환되어, 여권의 TICKET 및 TRAVEL HISTORY 모달에 사용됩니다. TRAVEL HISTORY에서 층을 선택하면 응답의 floorId로 층 상세 콘텐츠 API를 호출해 본문을 표시합니다.
유형: GET
URL: /passport/visits/{visitLogId}
상태: 시작 전
인증: 필요

### Path Parameters

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| visitLogId | number | Y | 방문 기록 ID |
