# 위시리스트 조회

카테고리: 위시리스트 / 쇼핑백
설명: 회원의 위시리스트 전체를 조회합니다. 비어 있으면 items는 빈 배열이며 totalCount는 0입니다.
유형: GET
URL: /wishlist
상태: 시작 전
인증: 필요

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "totalCount": 3,
    "items": [
      {
        "wishlistId": 12,
        "productId": 1,
        "name": "Ottomar 비세토스 위켄더",
        "price": 1750000,
        "colorName": "",
        "imageUrl": "https://.../ottomar.jpg"
      }
    ]
  }
}
```
