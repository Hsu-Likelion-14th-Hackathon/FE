# 위시리스트 담기

카테고리: 위시리스트 / 쇼핑백
설명: 상품을 위시리스트에 추가합니다. 저장된 데이터는 Boarding Pass 발급 시 취향 데이터로 활용됩니다. 이미 담긴 색상이면 그대로 유지되며 중복 저장되지 않습니다.
유형: POST
URL: /wishlist
상태: 시작 전
인증: 필요

### Request Body

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| productColorId | number | Y | 색상 단위 찜 (이거까지는 추후논의라 하긴했는데 아무리 생각해도 해야될 거 같아서 일단 구현..) |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "wishlistId": 12,
    "productColorId": 1,
    "isWished": true
  }
}
```

**404**

```json
{
  "isSuccess": false,
  "code": "PRODUCT_NOT_FOUND",
  "message": "존재하지 않는 상품입니다."
}
```
