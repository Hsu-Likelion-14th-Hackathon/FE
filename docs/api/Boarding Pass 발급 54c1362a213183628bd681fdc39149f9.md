# Boarding Pass 발급

카테고리: Boarding Pass
설명: 설문 응답을 제출하고 Boarding Pass를 발급합니다. 발급 시점의 위시리스트·쇼핑백 데이터가 티켓에 스냅샷으로 저장되며, 온라인 이용 기록이 없으면 설문 응답 기반으로 상품이 선정됩니다. 발급과 동시에 AI 추천 동선이 계산되어 저장됩니다. dataConsent가 false면 위시리스트·쇼핑백을 읽지 않고 설문 응답만으로 상품을 선정합니다.
유형: POST
URL: /boarding-passes
담당자: 박세웅
상태: 시작 전
인증: 필요

### Request Body

| **이름** | **유형** | **필수** | **설명** |
| --- | --- | --- | --- |
| dataConsent | boolean | Y | 위시리스트·쇼핑백 데이터 연동 동의. `false`면 온라인 기록 없이 설문 기반으로만 상품 선정 (개인정보 이슈때매 넣은 프로세스입니다) |
| answers | array | Y | 설문 응답 배열. 필수 문항(Q1~Q5)은 모두 포함 |
| answers[].surveyQuestionId | number | Y | 문항 ID |
| answers[].surveyOptionId | number | null | 조건부 | `SINGLE_SELECT`면 필수. `TEXT`(Q6)면 `null` 또는 생략 |
| answers[].textAnswer | string | null | 조건부 | `TEXT`(Q6) 자유 입력. 최대 200자. 미입력 시 `null`/생략 가능 (Q6는 선택 문항) |

```json
{
  "dataConsent": false,
  "answers": [
    { "surveyQuestionId": 1, "surveyOptionId": 1 },
    { "surveyQuestionId": 2, "surveyOptionId": 4 },
    { "surveyQuestionId": 3, "surveyOptionId": 9 },
    { "surveyQuestionId": 4, "surveyOptionId": 14 },
    { "surveyQuestionId": 5, "surveyOptionId": 16 },
    { "surveyQuestionId": 6, "surveyOptionId": null, "textAnswer": "트렁크 보고 싶어요" }
  ]
}
```
