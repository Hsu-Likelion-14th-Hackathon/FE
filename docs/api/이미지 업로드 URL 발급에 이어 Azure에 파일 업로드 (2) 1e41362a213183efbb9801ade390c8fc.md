# 이미지 업로드 URL 발급에 이어 Azure에 파일 업로드 (2)

카테고리: AI 가상 피팅
설명: 위 api에서 받은 uploadUrl로 로컬 이미지 파일을 올립니다. 우리 백엔드가 아니라 Azure Blob으로 직접 요청합니다.
유형: PUT
URL: {uploadUrl} 전체 문자열
담당자: 박세웅
상태: 완료
인증: 불필요

**Bearer JWT 넣지 말 것 (URL에 SAS 포함)**

### **Headers (필수)**

| **이름** | **값** |
| --- | --- |
| Content-Type | 1번 요청과 동일 (`image/jpeg` 또는 `image/png`) |
| x-ms-blob-type | `BlockBlob` |

### **Body**

- `multipart/form-data` 아님
- **raw binary** (파일 바이트 그대로)
- 예: `fetch(uploadUrl, { method: 'PUT', headers: {...}, body: file })`

### **성공**

- HTTP `201` 또는 `200`
- 응답 바디는 보통 비어 있음

### **실패 시 자주 보는 원인**

| **증상** | **원인** |
| --- | --- |
| `MissingRequiredHeader` / `x-ms-blob-type` | 헤더 `x-ms-blob-type: BlockBlob` 누락 |
| `InvalidAuthenticationInfo` | Bearer 토큰을 Authorization에 넣음 → **제거** |
| `BlobNotFound`로 URL 열림 | 아직 PUT 성공 전인데 조회함 / 업로드 실패 |
| 403 / AuthenticationFailed | `uploadUrl` 만료(5분) → 1번부터 다시 |
- 2번 호출 시 URL = `uploadUrl` 전체, **Bearer 제거**
- 2번 헤더에 `x-ms-blob-type: BlockBlob` 포함
- 2번 body는 `FormData`가 아니라 **File/Blob 자체**
- `expiresIn`(300초) 안에 2번 완료
