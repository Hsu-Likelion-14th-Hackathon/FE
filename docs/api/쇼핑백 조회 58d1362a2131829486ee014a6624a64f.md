# 쇼핑백 조회

카테고리: 위시리스트 / 쇼핑백
설명: 회원의 쇼핑백 항목 전체를 조회합니다. 비어 있으면 items는 빈 배열입니다.
유형: GET
URL: /shopping-bag
상태: 시작 전
인증: 필요
