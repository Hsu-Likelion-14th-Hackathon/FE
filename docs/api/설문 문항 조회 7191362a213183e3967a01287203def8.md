# 설문 문항 조회

카테고리: Boarding Pass
설명: Boarding Pass 발급 전 취향 설문 문항과 선택지를 순서대로 조회합니다. 총 6문항이며 Q6는 자유 텍스트(선택 입력)입니다. 문항 내용은 서버에서 관리되어 변경 가능합니다.
유형: GET
URL: /surveys/questions
담당자: 박세웅
상태: 완료
인증: 필요
