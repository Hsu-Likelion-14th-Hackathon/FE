# 상품 상세 조회

카테고리: 상품
설명: 상품 상세 정보를 조회합니다. 색상별로 이미지 목록과 사이즈 목록이 중첩되어 반환됩니다. productColorId는 위시리스트·AI 피팅에, productSizeId는 쇼핑백 담기에 사용합니다.
유형: GET
URL: /products/{productId}
상태: 시작 전
인증: 불필요

### Path Parameters

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| productId | number | Y | 상품 ID |
