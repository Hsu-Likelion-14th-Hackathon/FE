# 쇼핑백 담기

카테고리: 위시리스트 / 쇼핑백
설명: 상품을 사이즈 단위로 쇼핑백에 담습니다. 구매 기능은 제공하지 않으며, 담긴 데이터는 Boarding Pass 발급 시 취향 데이터로 활용됩니다. 재고 부족 시 실패합니다.
유형: POST
URL: /shopping-bag
상태: 시작 전
인증: 필요

### Request Body

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| productSizeId | number | Y | 사이즈까지 특정 |
| quantity | number | N | 기본값 1 |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "shoppingBagItemId": 5,
    "productSizeId": 1,
    "quantity": 1,
    "totalCount": 2
  }
}
```

**404**

```json
{
  "isSuccess": false,
  "code": "PRODUCT_SIZE_NOT_FOUND",
  "message": "존재하지 않는 상품 사이즈입니다."
}
```

```json
{
  "isSuccess": false,
  "code": "OUT_OF_STOCK",
  "message": "해당 상품의 사이즈 재고가 부족합니다."
}
```
