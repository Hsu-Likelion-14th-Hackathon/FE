# 쇼핑백 항목 삭제

카테고리: 위시리스트 / 쇼핑백
설명: 쇼핑백에서 항목을 제거합니다.
유형: DELETE
URL: /shopping-bag/{shoppingBagItemId}
상태: 시작 전
인증: 필요

### Path Parameters

| 이름 | 유형 | 필수 | 설명 |
| --- | --- | --- | --- |
| shoppingBagItemId | number | Y | 쇼핑백 항목 ID |

### Response

**200**

```json
{
  "isSuccess": true,
  "code": "COMMON2000",
  "message": "성공입니다.",
  "result": {
    "shoppingBagItemId": 5,
    "totalCount": 0
  }
}
```

**404**

```json
{
  "isSuccess": false,
  "code": "BAG_ITEM_NOT_FOUND",
  "message": "쇼핑백에 없는 항목입니다."
}
```
