## 1. 프로젝트 개요

- 프로젝트명
    - 미정
- 핵심 키워드
    - 여행, Boarding Pass, 비행기
- 목적
    - `온라인 행동 데이터(찜/장바구니 등)`를 `오프라인 매장 경험`으로 자연스럽게 전환/연결

    스토리텔링 강화
    - 구매 후 디지털 여권형식의 히스토리 기록을 통한 LTV 극대화

## 4. 단계별 상세 기능 명세

### 📍 [구매 전] 온라인: 고객 구매 데이터 기반 보딩 패스 발급

- 주요 기능
    - 자사몰 웹사이트 내 데이터 수집
        - 자사몰 내 하트(찜하기), 장바구니 담기, 과거 구매 이력, 최근 조회 상품 데이터 스크랩
    - 디지털 보딩 패스(Boarding Pass) 생성
        - 발급 시점의 데이터를 기반으로 실시간 커스텀 티켓 이미지 생성
        - 모바일 앱/웹, 애플 월렛, 카카오톡 알림톡으로 저장 가능
        - 티켓 내 고유 바코드/QR코드 포함
- 사용자 UX Flow
    1. 자사몰 접속 후 상품 탐색 (찜/장바구니 담기)
    2. `[MCM Boarding PASS 발급하기]` 버튼 클릭 OR `행사 팝업 페이지` 만들기
    3. 현재 취향이 반영(QR 코드 형식으로) 된 **"MCM Boarding Pass"** 발급 완료
    

### 📍 [구매 중] 오프라인: 비행기 컨셉 키오스크 & 동선 안내

- **주요 기능**
    - 비행기 창문(Airplane Window) 디스플레이 키오스크
        - 매장 입구/주요 동선에 비행기 좌석 및 창문 형태의 인터랙티브 디스플레이 배치
        - 보딩 패스 QR/바코드 스캔 시 개인 맞춤 화면 전환
    - 개인화 매장 동선 제안
        - 위시리스트/쇼핑백 상품 및 사전 설문 기반 MCM 전시회 동선 안내
        - 층별 상세 안내를 통해 디지털 전시회 도슨트 역할
        

### 📍 [구매 후] MCM Passport & 보상판매 리사이클링 서비스

- 디지털 MCM Passport (구매/방문 이력 관리)
    - **여권 디자인 UX :** 실물 여권 형태의 모바일 UI 구현
    - **여권 스탬프 리워드:**
        - 오프라인 매장 방문 스캔 시  **방문 스탬프**
        - 보딩패스 (비행기록 히스토리 저장)

## 5. 비즈니스 모델 (강화 방법 추가해야함)

- 경험 기반 O2O 매출 증대
    - 온라인 데이터(보딩패스)를 활용해 오프라인 매장 방문 및 맞춤 추천 동선을 유도하여
    매장 전환율(CVR) 및 객단가 상승

- 데이터 기반 리텐션 강화 (재방문 락인 · LTV 상승)
    - 설문·위시리스트·AI 피팅 데이터가 쌓일수록 추천 정확도가 높아지는 구조. 1회성 방문이 아니라 반복 방문을 설계에 내장한다.
    - 시즌/컬렉션 교체 시 개인화 프로필 기반 알림으로 재방문 트리거 (예: "지난번 HORIZON 층에서 담은 아이템, 이번 시즌 신제품으로 이어집니다")
    - 재방문 유저 대상 동선 추천 고도화(누적 데이터 기반) → 신규 유저 대비 재방문 유저의 CVR 격차를 벌리는 것이 목표
    - DAU/MAU 비율(스티키니스)을 핵심 리텐션 지표로 관리 — 단순 설치·다운로드가 아니라 "실제로 자주 돌아오는 서비스"인지를 증명

- 데이터 플라이휠 → MD/상품기획 연계 (비용 효율화)
    - 설문·동선·피팅 데이터를 매장 밖에서도 활용 가능한 자산으로 전환. 직접 매출이 아니라 재고·마진 효율화 관점의 비즈니스 가치.
    - 층별 관심도·피팅 선호 데이터를 MD팀에 정기 리포트로 제공 → 신제품 수요예측 정확도 향상
    - 데드스톡 감소, 시즌 발주 최적화로 마진율 개선
